Conectar à fonte de dados

O painel lê os dados que o Apps Script publica no Firebase Realtime Database. Cole a URL do seu banco (termina em firebaseio.com).

Onde encontro essa URL?
  1. No Firebase Console › Realtime Database.
  2. No topo da aba Dados aparece a URL, tipo https://seu-projeto-default-rtdb.firebaseio.com.
  3. Confira nas Regras que busca_ativa tem ".read": true.
  4. No Apps Script, rode sincronizar ao menos uma vez para popular o banco.

A URL fica salva só neste navegador. Para publicar fixo no GitHub Pages, cole a URL em CONFIG.FIREBASE_URL no topo do index.html.
